# Smart Emergency Hospital Allocation System

A Data Structures and Algorithms (DSA) project developed in C that simulates emergency patient allocation across hospitals using:

- Priority Queue (Heap)
- Dijkstra's Algorithm
- Graphs
- Hospital Resource Management
- Emergency Patient Prioritization

## Features
- Patient triage system
- Shortest-path hospital selection
- Waiting queue management
- Real-time metrics
- Admission and discharge management

## Technologies
- C Programming
- Data Structures & Algorithms
